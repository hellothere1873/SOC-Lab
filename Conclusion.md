# What I learned

Through this lab I gained practical experience with deploying and configuring Elastic Stack, endpoint telemetry collection, Sysmon, Fleet, detection rules, dashboards, attack simulation, investigation, ticketing, and automated endpoint response.

One of the biggest things I learned was that collecting telemetry is only the first step. The same attack can generate a large amount of legitimate and irrelevant data, so detection and investigation require filtering the useful events and understanding the context behind them.

I also encountered several configuration and compatibility issues throughout the lab, which required troubleshooting rather than simply following the tutorial. These included networking, firewall configuration, agent enrollment, RDP tooling, XAMPP/osTicket, and Elastic integrations.
