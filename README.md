# SOC-Lab
I am creating this SOC-Lab to learn how to draw logical diagrams, setup and configure Elastic Logstash and Kibana (ELK), attack detect and investigate, create alerts and dashboards, setup and integrate a ticketing system.



What I built:

Elastic Stack / Kibana

Fleet Server + Elastic Agents

Windows Server telemetry with Sysmon

Linux SSH honeypot

RDP/SSH attack simulations

Detection rules and dashboards

Mythic C2 / Apollo attack simulation

osTicket alert integration

Elastic Defend automated host isolation
